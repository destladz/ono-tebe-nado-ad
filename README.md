# Оно тебе надо

Учебный проект — сайт-аукцион вещей, в которые никто не верил.

## О проекте

Одностраничный сайт с адаптивной вёрсткой. На странице представлены шапка сайта, главный экран, карточки лотов, информационный блок и подвал с контактами и социальными сетями.

## Технологии

- HTML5
- CSS3
- SCSS
- БЭМ — методология именования классов
- Flexbox и Grid
- Git и GitHub

## Структура проекта

- `index.html` — главная страница
- `styles/` — стили проекта
  - `base/` — базовые SCSS-файлы
  - `sections/` — стили отдельных секций
  - `global.css` — глобальные стили
  - `style.scss` — основной SCSS-файл
  - `style.css` — собранный CSS
- `fonts/` — шрифты Raleway
- `images/` — изображения и иконки
- `js/` — JavaScript-файлы

## Запуск проекта

Откройте файл `index.html` в браузере.
