# Оно тебе надо

Учебный проект — сайт-аукцион вещей, в которые никто не верил.

## О проекте

Одностраничный сайт. На странице представлены шапка сайта, главный экран, карточки лотов, информационный блок и подвал с контактами и социальными сетями.

## Технологии

- HTML5
- CSS3
- Flexbox и Grid
- Git и GitHub

## Структура проекта

- `index.html` — главная страница
- `styles/` — стили проекта
  - `global.css` — глобальные стили
  - `style.css` — собранный CSS
- `fonts/` — шрифты Raleway
- `images/` — изображения и иконки

## Запуск проекта

Откройте файл `index.html` в браузере.
